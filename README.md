## أداة الحسابات

```bash
cd .claude/skills/egx-investing/scripts

# العائد الحقيقي (القسمة مش الطرح) + مقارنة بالشهادة
python3 egx_calc.py real-return --nominal 31.2 --inflation 16.5 --certificate 19

# العائد بالدولار بعد حركة الجنيه
python3 egx_calc.py usd-return --nominal 31.2 --fx-start 47.8 --fx-end 52.0

# حجم المركز بالمخاطرة + فحص السيولة
python3 egx_calc.py position-size --capital 500000 --risk-pct 1.5 \
    --entry 95 --stop 86 --adv 2000000

# التكلفة الحقيقية للصفقة شاملة الدمغة والـ spread
python3 egx_calc.py cost --value 100000 --spread-pct 0.5 --trades-per-year 20

# السهم مقابل الشهادة البنكية (مع اختبار ضغط)
python3 egx_calc.py compare --pe 8 --div-yield 6 --growth 25
```

## الأفكار الأساسية

**1. العائد الاسمي مش معلومة.** في مصر لازم تقيس على تلاتة: التضخم (16–17%)، الشهادة البنكية (~19%)، والدولار. سهم كسب 18% خسر أمام الشهادة.

**2. اقسم ولا تطرح.**
```
العائد الحقيقي = ((1 + العائد) ÷ (1 + التضخم)) − 1
```
عند مستويات التضخم المصرية، الفرق كبير كفاية إنه يقلب الاستنتاج.

**3. تصنيف العملة قبل التقييم.** مُصدّر بيكسب دولار؟ محلي؟ مستورد تكاليفه بالدولار؟ مع توقعات الجنيه 52–55، ده غالبًا أهم من السعر.

**4. الهوامش هي الإشارة.** الإيرادات بتزيد مع التضخم لوحدها. "إيرادات طالعة + أرباح نازلة" = ضعف هيكلي.

**5. المؤشر مش متنوّع.** أكبر 3 أسهم في EGX 30 ≈ نص وزن المؤشر.

**6. حدّد الحجم بالمخاطرة مش بالثقة.** والوقف مابيحميش من الفجوة السعرية — والسوق المصري بيفتح الأحد بعد يومين أخبار عالمية متراكمة.
